撤回这条记忆？

撤回后不再进入已发布记忆。原文仍保留并占用容量；需要重新使用时，可以复制成新候选，原撤回记录不改变。

检索并交给主导 AI

仅在当前空间检索已发布内容，不生成结论。复制不会自动调用模型；粘贴到云端软件会向该服务发送这些内容，请先检查。

本机性能

每 10 秒采样；关闭后停止轮询。CPU 为两次采样间均值，GPU 为驱动报告的采样值。

模型占用：未知。尚未绑定模型与进程，整机 GPU 占用不能当成某个模型占用。GPU 暂支持 NVIDIA 驱动接口。

静态图片仅保存在本机；关闭壁纸可恢复纯色。暂不支持视频壁纸或系统桌面穿透。

连接

仅支持本机回环地址。模型 Base URL / 模型 ID / Token 在面板的「模型与连接」中配置。

公共记忆池

默认已有一个本机公共池。公共表示可按授权共享，不表示已发布到网络。

容量不足怎么办？

保存会被阻止，已保存内容不变、输入框保留。可先复制未保存内容，再在「编辑架构」中提高上限（目前最多 200,000 字符），或新建空间手动拆分。撤回仍保留原文，不释放容量。不会自动删除、压缩或外发。

拟采用闲时队列：任务执行优先，记忆提炼等待；输出必须进入候选并保留来源。无模型时使用当前的本机关键词检索，不伪造摘要。架构修改仍需你的单次确认。
