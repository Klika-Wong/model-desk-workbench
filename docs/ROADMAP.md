# 功能状态与后续范围

开发预览不是完整产品验收。以下项目明确保留，不因发布而标为完成。

| 方向 | 当前状态 | 后续验收重点 |
| --- | --- | --- |
| 桌面软件 | Electron 窗口、托盘、小窗可运行 | 安装包、全新机器安装、退出与升级 |
| 统一 UI | 新导航、主题、壁纸与记忆画布已有 | 清除旧管理面板割裂，持续验证窄窗和对比度 |
| 模型连接 | 本机探测与执行端配置已有 | 不同软件版本、掉线恢复、原生入口可见性 |
| 主导软件 | 存在集成代码与任务传递 | 从工作台无缝跳转所选主体，原软件中执行与双向可见 |
| 多 Agent | 路由、队列、记录和验收基础 | 多组主导讨论、交叉评审、实时讨论流与并发公平性 |
| 额度与成本 | 有供应商适配与记录 | 缺失数据明确未知；消除桌面路由固定 token 估计 |
| 性能监测 | 性能视图、小窗和低频读取基础 | 每个模型 GPU/CPU 归因与开销准确度 |
| 单/多 Agent 对比 | 尚无可信配对实验 | 同一任务、质量门槛、耗时、tokens、资源和成本一起比较 |
| 记忆管理 | 本地空间、检索、结构编辑与预览 | 可控嵌套、迁移恢复、容量不足与过期记忆处理 |
| AI 提炼 | 可手动复制结构评估提示词 | 本地模型闲时队列、冲突调度、溯源与人工授权 |
| 项目保密 | 应用层项目范围与发送检查 | 更强隔离、越界测试和适当的静态加密方案 |

小模型能力界限只能由特定版本、任务与验收结果逐步校准。一次短回答成功不能证明其能做代码审计，也不能保证后续长任务稳定。不可把声明的能力标签当成实测评分。
