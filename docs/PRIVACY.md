# 公开源码与隐私

本次发布通过源码清单复制生成，没有复制运行中的配置、账户、模型权重、私人记忆、任务数据库、聊天记录、截图或旧 Git 历史。测试使用虚构项目路径和模型编号。

## 本地运行后产生的数据

- 服务配置与凭据、执行软件账户数据必须留在本机；不要提交 `.env`、模型配置或账户配置。
- 项目任务历史保存在项目 `.model-desk`，默认不进入版本控制。
- 桌面记忆保存在 Electron 用户数据目录；不要把它当作公开示例上传。
- 导出的上下文、结构标签、日志和截图仍可能包含敏感信息，发送前需要检查。

`.gitignore` 是防误提交措施，不能阻止程序访问文件，也不能删除已经发布的秘密。

## 外发边界

连接本地服务不代表所有后续调用都在本机。选择在线模型或已登录的第三方软件后，用户确认的输入会交给该执行服务。公共池不自动授权外发。不要把敏感项目选作功能演示项目。

权限检查、回环地址限制、工具参数检查都是应用层措施。当前没有宣称 OS 沙箱或加密保险箱；管理员启动也不会赋予额外的保密性。需要系统管理员权限的外部软件，应根据本机实际配置单独判断。

## 发布前检查

运行 `python scripts/check_public_source.py` 扫描已清点的发布源码。它检查常见密钥格式、机器专属标识与禁止发布的文件类型，并仅输出路径、行号和规则名称，不输出命中内容。扫描不是完整安全审计或无泄漏保证。

发现真实密钥已公开时，先在服务商处吊销/轮换；随后清理仓库及历史。仅删除当前文件不能使旧密钥重新安全。
