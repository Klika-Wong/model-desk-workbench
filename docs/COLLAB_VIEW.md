# 协作视图：谁在跟谁说话

更新：2026-11-07。功能位置：桌面导航「模型状态」→ 协作视图。

> 2026-11-08：画布已升级为基建式房间（后墙 / 地板 / 家具 / 座位制归位），详见
> [协作舱](COLLAB_ROOM.md)；本文中与「画布外观」相关的旧描述以该文为准。

这是**多模型交互的可视化**，不是动画演示：一轮讨论里，每位模型看到的 prompt 会注入前面所有人的发言，
本页把这条真实的数据流画出来，不推测「谁赞同谁」，也不替模型编造内容。

## 页面构成

- 左侧画布：每个模型一个拟人角色节点，可拖动，位置存在本机，刷新后保留。
- 连线：从「被参考的发言人」指向「正在生成的发言人」；当前那条线流动高亮，
  点某个角色后只高亮与它相关的连线。
- 右侧「本轮记录」：按顺序列出每条发言、该条参考了几条、正文摘要；点条目回选角色。
- 状态栏如实说明当前是第几条、参考了前面几条，以及本轮结束时有几位产生了有效输出。

讨论在本机队列里**串行**执行，视图如实呈现先后，不假装并行。

## 形象与交互

| 模型 | 默认形象 |
| --- | --- |
| DeepSeek / dsh | 大肥鱼（`assets/pets/*.gif`） |
| Claude / Anthropic | 像素螃蟹 |
| 其余全部 | Q 版拟人少女，按模型 id 换发色，同屏不撞脸 |

每个角色的六种状态各自对应一张自带 SMIL / CSS 动效的图：待机、思考、正在输出、已发言、被戳、被拖。
点角色右上角的 `⇄` 可循环切换形象（拟人少女 → 螃蟹 → 大肥鱼 → 品牌标识币 → 表情），选择存本机。

| 操作 | 结果 |
| --- | --- |
| 单击角色 | 选中，高亮相关连线与对应记录 |
| 双击角色 | 戳一下，切到「被戳」动画 1.7 秒并冒一句短反馈 |
| 拖动角色 | 切到「被拖」动画，位置实时落盘，连线跟随重画 |
| 点名字 | 改形象 ID，贯穿对话下拉、派发页、发言记录 |
| 点右侧记录 | 回选对应角色 |
| 勾选「收成桌宠」 | 画布收成右下角一只，连线与记录一并隐藏 |

切回本页只刷新名字与连线，不重建节点，本轮讨论记录不会因切页丢失。

## 多形象与场景（2026-11-07 晚补充）

- 每个模型至少两个专属形象（15 个模型 × 标准版 / Q 版 = 30 个手绘 Q 版角色，来自 llm-pet）。
  角色下方直接摆两个缩略图，`＋` 打开完整形象库；旧的通用 `⇄` 按钮已移除。
- 每个角色的九种动作由 `spritesheet.webp` 的 CSS sprite 播放：待机、右移、左移、招手、跳跃、
  失败、等待、工作、审查。状态切换只改动作行，动画不跳帧。
- 场景「讨论中 / 工作中 / 摸鱼中」切换画布背景与角色动作；**只改视觉，不改真实任务状态**。
- 模型 ID 完整显示：复选框列表、角色名、状态列表、发言记录都不再截断。
- 右侧统一控制面板包含场景、模型状态、本轮记录与对话输入；卡片与面板去掉硬边框。
- 连线带流动光点，正在发言的角色转向它参考的对象，被参考的角色会招手。

授权见 `desktop/assets/characters/roster/NOTICE.md`：**署名 ZipZipPipe、仅限非商业**；
DeepSeek 形象另遵循 CC BY-NC-SA 4.0。独立悬浮桌宠见 [PET_DESKTOP.md](PET_DESKTOP.md)。

- 讨论可随时「停止本轮」，并有 180 秒超时兜底。
- 连线渲染已拆分结构与几何，拖拽不再重建 SVG（修掉闪烁与卡顿）。
- 只显示在线 / 已连接模型；未连接的给启用引导，不假装能一键唤醒。
- 头顶 ID 条里有一枚状态情绪标，跟 `setActorState()` 的真实派发状态同步：生成中 ✨、
  正在输出 🔥、已发言 👍、失败 ❌、等待 💤；待机不显示。它只是状态的可视化，
  **不推测模型情绪**。图标是本地 Fluent Emoji SVG（MIT），页内小窗模式下随 ID 条一起隐藏。
