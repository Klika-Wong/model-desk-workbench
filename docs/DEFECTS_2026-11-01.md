# 2026-11-01 缺陷核实与修复

本轮范围是桌面模型页、对话发送和高级设置的异步交互，不是全部产品功能完成验收。

| 缺陷 | 修复前的独立复现 | 修复结果 |
| --- | --- | --- |
| 高级设置迟到加载抢回导航 | 打开请求挂起，切到对话，再返回成功；导航重新成为模型页 | 打开请求串行，离开后失效；主进程在发现服务和加载完成后检查取消状态 |
| 连点发送重复派发 | 挂起项目读取后连续发送，桩接口收到两次请求 | 首次异步操作前加锁，只派发一次 |
| 准备期间撤销确认无效 | 挂起项目读取，取消确认，恢复读取；仍派发一次 | 派发前检查确认、模型、项目、记忆与历史范围；变化后不发送 |
| 离线连接区空白及环境依赖测试 | 服务未运行时没有节点；冒烟检查硬编码要求4节点 | 显示明确离线状态，节点功能使用合成数据单独验证 |

同时禁止在对话准备或执行期间清空记录，以免丢失任务跟踪。派发通信失败不再断言任务一定没有发出，应先检查任务记录。额度文档纠正为“读取服务快照，服务端可能按策略更新余额”，不再保证完全没有外部请求。

## 验证

- `async-defects-verify.cjs`：7个真实Electron渲染环境的桩接口用例，含迟到回复、重复提交、撤销确认、关闭再开、崩溃、换项目和执行中清空。
- `embed-lifecycle.test.cjs`：2个主进程函数测试，覆盖发现服务和加载页面时取消。
- 数据规范化相关测试9项通过，既有界面回归21项通过，桌面冒烟检查通过。
- 测试未调用真实模型，也不代替新机器安装或所有功能验收。
