# 模型与额度

侧栏「模型与额度」默认打开桌面统一总览，不再直接嵌入复杂配置面板。

- 可按名称、来源、执行端搜索，筛选本地、云端或已启用模型。
- 显示执行端就绪情况和上次调用检查，连接就绪不等于任务运行中。
- 「用于对话」只选中模型，进入对话页后仍需确认发送；不会发消息或更改全局默认。
- 执行端未就绪、模型停用、执行端锁定其他模型时不可选择。配置说明与能力声明不等于实测成绩。
- 「添加模型连接」可直接新增本地/API连接；模型行内「执行软件」可更改后续新任务的执行软件，见[连接设置说明](MODEL_CONNECTIONS.md)。
- 「高级设置」保留已有连接的地址/密钥编辑、执行端当前模型选择及原生账户设置。

## 额度与刷新

Codex 额度窗口分别展示，数值 0 与未知分开。同步失败时有缓存则显示上次数据，无缓存则明确提示同步失败。支持的服务商余额只展示有限、非负金额；可能共享的账户余额不会合计。本地模型不适用云端额度，但仍消耗计算资源。

WorkBuddy/ZCode 额度尚未接入这个统一页，需要在原软件或高级设置查看。页面每 30 秒在可见时读取服务快照，不发起模型推理。服务端可能按缓存策略查询已配置服务商的余额，因此不承诺刷新过程完全没有外部请求。服务断开时保留上次快照并禁止从旧快照选择模型，恢复连接后重新可选。

对话在准备发送时即锁定重复提交；派发前再次检查项目、模型和记忆范围。准备期间撤销确认或改变发送范围会取消这次准备，需要重新确认。任务执行期间暂不可清空对话，以免丢失任务跟踪。高级设置加载中切走页面时，迟到结果不会再抢回界面。

## 验证与限制

使用合成数据验证搜索、选择、断线恢复、延迟响应、0/未知额度和深浅主题。`model-overview-ui-verify.cjs` 在 Electron 中检查 600/800/1280 像素宽度，可通过 `MODEL_DESK_SCREENSHOTS` 指定本机截图目录。

这些检查不代表付费模型的调用验收。统一页尚未取代所有高级配置，也未完成主体软件原生跳转、逐模型资源归因或全部产品需求。
