# 在桌面添加模型连接

先运行本机协作服务，在侧栏打开「模型与额度」，等待模型列表读取完成。没有连接服务时，添加按钮不可用。

1. 点击「添加模型连接」。
2. 填写显示名称、服务类型、OpenAI 兼容接口的 Base URL 和服务中实际存在的模型 ID。
3. 本地 Ollama 的默认接口地址为 `http://127.0.0.1:11434/v1`。保存连接不会安装或下载模型。
4. 如需认证，展开「认证与输入 / 输出限制」，填写 API 密钥或环境变量名，两者只选一种。输入/输出上限需与实际服务相符。
5. 选择后续新任务使用的执行软件，然后保存。

保存连接不会自动测试或调用模型。连接属于全局配置，所有项目均可选用；后端在没有默认模型时，会将首个启用模型设为默认。

## 更改执行软件

已有 API/本地模型的行内有「执行软件」按钮，可选择 DeepSeek Harness、Pi Agent 或沿用全局默认。保存只提交该字段，保留已有接口地址、密钥、价格、预算及其他配置。排队中和执行中的任务继续使用其原执行端。

WorkBuddy/ZCode 原生账户模型不显示此按钮，它们使用对应原生执行端。已有连接的地址、密钥编辑及执行端当前模型选择，仍在「高级设置」中。

## 保存与错误

- 表单提交或关闭后清空密钥输入；切换服务类型也会清空认证输入。已有密钥不会读取回填。
- 设置请求仅发送到当前已读取列表的本机服务，不自动换到其他端口保存。
- 保存中禁止重复提交和关闭表单。失败时保留普通字段，密钥需重新输入。
- 网络中断可能发生在服务保存之后；提示结果未确认时先刷新模型列表，不要连续重复添加。
- 这些交互已用隔离HTTP与Electron桩验证，不能据此声称所有提供方或新机器配置都能使用。
